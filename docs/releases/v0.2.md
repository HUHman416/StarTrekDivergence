## Star Trek Divergence v0.2 — Alpha

**Made entirely with ChatGPT, with concepts and ideas by HUHman.**

### New in this version

- **Your ships, your identity:** edit ship names and registry numbers, name fleets, and change fleet designations.
- **Guided academy:** an optional five-step tutorial, contextual explanations, and the ability to skip or replay it.
- **Portable campaigns:** export and import JSON saves, preview imports before replacing a campaign, and migrate v0.1 save data.
- **Independent fleets:** organize up to three fleets and twelve ships; transfer vessels in the same system, travel over time, scout, escort convoys, and patrol.
- **Branching exploration:** four discoverable missions with choices, two-month follow-ups, and outcomes influenced by earlier decisions.
- **More responsive diplomacy:** trust, treaty proposals and counteroffers, border agreements, research cooperation, aid requests, earned favors, and consequences for betrayal.
- **Expanded bridge command:** individual power allocation, subsystem targeting, science scans, and the option to disable engines instead of destroying hulls.
- **Distinct vessels:** explorers, tactical cruisers, science ships, and support tenders have different strengths and assignment bonuses.

### Download and play

Choose **StarTrekDivergence-v0.2.html** below. The optional ZIP contains the same game and a quick-start guide. No installation, server, or account is required. Start with **Start tutorial** on the command overview, or open **Academy & saves** at any time.

### Keeping a campaign

For v0.2 and later, use **Academy & saves → Export campaign**, then import the JSON in the next version. Automatic saves remain tied to the browser and, for downloaded games, may be tied to the file's location. Keep your old HTML file until you have verified your campaign in the new version.

The original v0.1 did not have an export button. Replacing it at the same file path in the same browser may retain its local save, depending on the browser. For reliable recovery of a v0.1 campaign, keep the old file and extract its `divergence.campaign.v1` local-storage entry through the browser's developer tools; the new importer accepts that raw JSON. Do not assume that opening a new filename transfers saves automatically.

### Validation and scope

42 simulation tests and an end-to-end Chromium walkthrough cover the tutorial, missions, fleets, diplomacy, combat, saves, and responsive layouts. The downloadable bundle is tested separately; the managed test browser does not permit direct `file://` navigation, so automated bundle checks use HTTP. The previous standalone prototype was successfully playtested by HUHman.

This is an **alpha browser release**, not a finished native desktop game. The Federation-focused founding chapter and six-system map remain deliberately small. Klingon and Romulan starts share the prototype story structure. Native Linux and Windows packaging, dedicated faction campaigns, and the later mod manager remain on the roadmap.
